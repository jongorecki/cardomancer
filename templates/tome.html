Coming soon

Query syntax.

Every bin gets a query. The grammar mirrors Scryfall's search — c:r for red cards, t:creature for creatures, usd>=1 for everything worth a buck or more. Local-only tokens (staple, salt, buylist:ck) require an enrichment refresh first.

Full grammar reference forthcoming.

Coming soon

Override bins.

Checking the Override column makes a bin evaluate before the rest. Use it for high-priority routes — "anything over $1" — that should bypass the color or rarity sort underneath.

Coming soon

Fallback bin.

The bin marked fallback catches every card that doesn't match any other query. Without one, unmatched cards crash the session.

Coming soon

Continuous sorting.

When continuous mode is on, the machine re-queues a new detect-and-sort cycle after every drop. Pauses when the source bin runs empty.

Coming soon

Per-bin card limit.

Once a bin fills past its limit, the machine pauses and asks for it to be emptied. Set the limit by the physical depth of your bin minus a safety margin.

Coming soon

ArUco calibration.

Place an ArUco marker in the bottom of each bin (IDs documented under Setup). The machine sweeps the X axis, spots each marker, and records the bin's X position automatically.

Coming soon

Drop-height tuner.

Dials in Z_DROP_OFFSET — the height above a bin from which cards are released. Run it once per physical bin layout; the value persists across sessions.

Coming soon

Source-bin empty probe.

The machine learns the depth of an empty source bin so it can tell when it has run out of cards. Recalibrate any time the source bin moves or changes height.

Coming soon

Detection review queues.

Scans that crossed the low-confidence threshold land in these queues — identity, foil, border, set symbol. Mark each as correct, wrong, or skip; verdicts feed future detector tuning.

Coming soon

Enrichment sources.

External data feeds — Scryfall Tagger, EDHREC, edhtop16, Commander Spellbook, CK buylist. Each one refreshes on its own cadence and surfaces in queries via tokens like staple, salt, buylist:ck.

Coming soon

Card-data update.

"Refresh prices" pulls the latest Scryfall bulk and re-prices the inventory in about a minute. "Run full update" additionally downloads new card images and rebuilds the pHash and DINOv2 embedding databases — slow, only needed when new sets release.

Coming soon

E-stop recovery.

After an emergency stop, the carriage is halted in place. Click "Reset & re-home" to clear the Marlin halt, home both axes, and resume the queued session.

Coming soon

Sort presets.

Built-in presets (color, rarity, EDH commander) ship with the kiosk. Save your own from the Sort tab — they persist under sort_configs/ and reload on next launch.

Coming soon

Moxfield integration.

Import a Moxfield wishlist by URL; pulled cards become a wishlist bin you can prioritise in a sort. Export the current collection back to Moxfield-format text from the Collection tab.

Coming soon

Wishlist + priority bins.

A bin can be configured to catch only cards in a given wishlist source. The bin overrides the regular sort so a wishlist hit lands there regardless of what the color query would otherwise do.

Coming soon

Boxes and dividers.

The collection database tracks where each card physically lives. Boxes hold dividers; dividers hold groups of cards. The locator tells you which divider to look in for any card matching a query.
