► How to use the sort window

Presets

  • Select a preset from the dropdown to load its bin rules. Built-in presets (by color, by rarity, by price) cannot be overwritten — use Save As… to create a user copy.
  • New starts a blank config. Save writes changes back to the current user preset file. Save As… creates a new preset. Delete removes a user preset.
  • The modified badge next to the header means you have unsaved edits.

Bin rules

  • Bins sets how many physical bin rows to show. Fallback bin is where cards go when no rule matches. Bin limit caps cards per bin (blank = unlimited).
  • Each row is evaluated top-down: the first matching rule wins, unless the Override column is checked.
  • Override bins are checked before all non-override bins. Use for high-priority routes like buylist:ck>=1 or cull:true that should bypass a color/rarity sort.

Query syntax

Queries borrow most of Scryfall's syntax. For the full reference see scryfall.com/docs/syntax. Card Sorter supports the basic fields below plus local enrichment tokens not available on Scryfall.

Basic fields

c:rColor — W U B R G or C (colorless). Combine: c:wr
t:creatureType line contains word. Also: t:land, t:artifact, t:instant
cmc<=3Mana value. Operators: < <= = >= >
usd<1.00TCGPlayer price in USD
r:mythicRarity — common uncommon rare mythic
otag:removalScryfall function tag. Fetched from API on load.

Enrichment fields requires enrichment refresh

staple:universalIn top EDHREC inclusion lists (appears in >5% of decks)
staple:cedhAppears in >15% of top-16 cEDH tournament decks
staple:archetypeTop card in ≥3 EDHREC archetypes (color, theme, or top-commander pages)
staple:anyAny staple tier (universal, cedh, or archetype)
salt>2EDHREC salt score above threshold. Range ≈ 0–4.
combo:trueAppears in a Commander Spellbook combo
buylist:ckCard is on CardKingdom's buylist (any price > 0)
buylist:ck>=1.00CK buylist price ≥ $1. Operators: < <= = >= >
cull:trueDead-weight flag: vanilla/french-vanilla AND no staple tier AND no CK buylist entry. Route these to a cull bin.
cull:falseNegation of cull:true — card has some value (has text, is a staple, or is on a buylist).

Moxfield integration deck/wishlist must be imported first

deck:<id>Card is in the imported Moxfield deck (any printing). Basic lands always excluded.
deck:<id>!exactCard matches the deck by exact printing (set + collector number).
wishlist:<user>Card is in <user>'s imported Moxfield wishlist (any printing). Basic lands excluded.
wishlist:<user>!exactWishlist match by exact printing (set + collector number).
Import a deck via POST /api/integrations/moxfield/deck/import or a wishlist via POST /api/integrations/moxfield/wishlist/import before using these tokens. Private wishlists return 401.

Logic & grouping

Space = AND  |  OR  |  - = NOT  |  (…) = group

Examples

  • -staple:any usd<1.00 — cheap non-staples (junk pile)
  • staple:cedh OR combo:true — high-value targets
  • (c:w OR c:u) t:creature cmc<=3 — cheap Azorius creatures
  • cull:true — vanilla cards with no buylist value (pair with Override bin)
  • buylist:ck>=1.00 — cards CK will pay $1+ for (pair with Override bin)
